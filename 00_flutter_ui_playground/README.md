# 📱 Track 0: Flutter UI Playground & Essentials

A foundational hands-on Flutter UI practice suite containing **11 essential UI apps and widgets**, organized in strict **Easy ➔ Hard** difficulty progression.

---

## 🚀 Features

- 🟢 **Level 1: Beginner Essentials (Simple State & Inputs)**:
  1. **Counter App** (`counter/`): Basic State management with `setState`.
  2. **Background Color Switcher** (`background_color/`): Dynamic state toggles.
  3. **Random Color Generator** (`random_color/`): Random RGB color generation.
  4. **Pass Message App** (`pass_message/`): Form input handling and controller state.
  5. **Random Quotes Generator** (`random_quotes/`): List arrays & random indexing.

- 🟡 **Level 2: Intermediate UI (Cards, Lists, Modals & PageViews)**:
  6. **Customer Testimonials Card** (`testimonials/`): Structured card layouts & styling.
  7. **Modal Dialogs & BottomSheets** (`modal_dialog/`): Custom dialogs, SnackBars, & BottomSheets.
  8. **Searchable Filterable List** (`filterable_list/`): Real-time search filtering logic.
  9. **Image Carousel Slider** (`image_carousel/`): `PageView` slider & dot indicators.

- 🔴 **Level 3: Advanced UI (Complex Logic & Custom Styling)**:
  10. **Full Calculator App** (`calculator/`): Multi-button calculator UI & mathematical expression evaluation.
  11. **Neumorphism Soft UI** (`neumorphism/`): Soft UI Neumorphism styling with custom `BoxShadow` & convex/concave depth.

## 🚀 How to Run Exercises

1. Install dependencies:
   ```bash
   cd 00_flutter_ui_playground
   flutter pub get
   ```

2. Run the main Playground Dashboard on Linux Desktop:
   ```bash
   flutter run -d linux lib/main.dart
   ```
